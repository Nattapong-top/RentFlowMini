# RentFlowMini

โปรแกรมจัดการห้องพักขนาดเล็ก พัฒนาด้วย C# WinForms, .NET 10 และ SQLite

## ภาพรวมโปรเจกต์

RentFlowMini เป็นโปรเจกต์สำหรับฝึกพัฒนาซอฟต์แวร์ โดยเน้นการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP), Clean Architecture และการพัฒนาแบบทดสอบนำ (Test-Driven Development: TDD)

ปัจจุบันโปรแกรมรองรับการจัดการห้องพักและผู้เช่า ตั้งค่าราคากลาง บันทึกมิเตอร์น้ำ-ไฟรายเดือน และสร้างบิลประจำเดือน ดูรายละเอียดล่าสุดที่ [docs/current-code-status.md](docs/current-code-status.md)

## เทคโนโลยีที่ใช้

- C#
- .NET 10
- Windows Forms (WinForms)
- SQLite (`Microsoft.Data.Sqlite`)
- xUnit สำหรับทดสอบโปรแกรม

## สถาปัตยกรรมระบบ

```text
WinForms UI (RoomForm + Tab Controls)
    |
    v
Application Services
(CreateRoomService, UpdateRoomRentService, CreateTenantService,
 SaveMonthlyMeterReadingService, UpdateBillingSettingsService,
 CreateMonthlyBillService)
    |
    v
Domain (Room, Tenant, Bill, BillingCalculator, MonthlyMeterReading,
        BillingSettings, Value Objects)
    |
    v
Repository Interfaces
    |
    v
Infrastructure (SQLite / In-Memory)
```

### ส่วนประกอบหลัก

- **Domain** — โมเดล `Room`, `Tenant`, `Bill`, `MonthlyMeterReading`, `BillingSettings`, `BillingCalculator` และ Value Objects เช่น `RoomNumber`, `Money`, `MeterReading`, `BillingPeriod`
- **Application** — Use Case ของห้องพัก ผู้เช่า มิเตอร์ ตั้งค่าราคา และสร้างบิล พร้อมสัญญา repository
- **Infrastructure** — SQLite Repository ที่แอปใช้จริงสำหรับทุกส่วน และ In-Memory Repository ที่ใช้ในเทสต์
- **UI** — WinForms แบ่งเป็นแท็บตามลำดับ: รายงานข้อมูล, บันทึกมิเตอร์, สร้างบิลประจำเดือน, จัดการผู้เช่า, จัดการห้องพัก และตั้งค่าพื้นฐาน
- **Tests** — Unit Tests, UI Tests และ Integration Tests สำหรับ SQLite ซึ่งใช้ไฟล์ในโฟลเดอร์ชั่วคราว ไม่ต้องติดตั้งฐานข้อมูล

## ความสามารถในปัจจุบัน

- เพิ่มห้องพักพร้อมค่าเช่ารายเดือนและสถานะยกเว้น Cable TV, แก้ไขค่าเช่าและสถานะยกเว้น (มีผลเฉพาะบิลที่ออกใหม่) และป้องกันเลขห้องซ้ำ
- เพิ่มผู้เช่าและผูกกับห้อง (หนึ่งห้องต่อผู้เช่าหนึ่งราย) และบันทึกการย้ายออก โดยเตือนเมื่อห้องยังไม่มีบิลของเดือนที่ย้ายออก
- ตั้งค่าราคากลาง: ค่าน้ำ ค่าไฟ ค่าจอดมอเตอร์ไซค์ ค่าจอดรถยนต์ และค่า Cable TV
- บันทึกมิเตอร์น้ำ-ไฟรายเดือน โดยดึงค่าก่อนหน้าจากรอบก่อนอัตโนมัติ และแก้ไขย้อนได้
- สร้างบิลประจำเดือน 6 รายการ (ค่าเช่า, น้ำ, ไฟ, จอดมอเตอร์ไซค์, จอดรถยนต์, Cable TV) พร้อมเลขใบแจ้งหนี้ ป้องกันบิลซ้ำ และออกบิลได้เฉพาะห้องที่มีผู้เช่า
- เลือกรอบบิลเป็นเดือนภาษาไทยและปี พ.ศ.
- เก็บข้อมูลถาวรใน SQLite ปิดแล้วเปิดใหม่ข้อมูลอยู่ครบ

## การติดตั้งสำหรับผู้ใช้

ผู้ใช้ไม่ต้องติดตั้ง .NET หรือฐานข้อมูล ใช้ไฟล์ `RentFlowMiniApp.exe` ไฟล์เดียวที่สร้างตามหัวข้อ [การสร้างไฟล์สำหรับแจกจ่าย](#การสร้างไฟล์สำหรับแจกจ่าย)

1. ใช้ Windows 10 หรือ 11 แบบ 64 บิต
2. สร้างโฟลเดอร์ เช่น `C:\RentFlowMiniApp` แล้วคัดลอก `RentFlowMiniApp.exe` ไปไว้ในโฟลเดอร์นั้น อย่าเก็บไว้ในโฟลเดอร์ Downloads หรือโฟลเดอร์ซิงก์คลาวด์
3. คลิกขวาที่ไฟล์ แล้วเลือก **ส่งไปยัง > เดสก์ท็อป (สร้างทางลัด)**
4. เปิดโปรแกรมจากทางลัด ถ้า Windows แสดงหน้าต่าง "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** หน้าต่างนี้ขึ้นเพราะไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล
5. ครั้งแรกให้ตั้งค่าตามลำดับ: แท็บ **ตั้งค่าพื้นฐาน** (ราคากลาง ชื่อหอพัก ที่อยู่ บัญชีรับโอน) → **จัดการห้องพัก** → **จัดการผู้เช่า** จากนั้นใช้งานประจำเดือนที่แท็บ **บันทึกมิเตอร์** → **สร้างบิลประจำเดือน** → **รายงานข้อมูล**

ข้อมูลเก็บไว้ที่ `%LocalAppData%\RentFlowMiniApp` ไม่ได้อยู่ในโฟลเดอร์ของโปรแกรม จึงลบหรือแทนที่ `RentFlowMiniApp.exe` ได้โดยข้อมูลไม่หาย

อัปเดตเป็นรุ่นใหม่: ปิดโปรแกรม กดสำรองข้อมูลก่อนตามหัวข้อ [การสำรองและกู้คืนข้อมูล](#การสำรองและกู้คืนข้อมูล) แล้ววาง `RentFlowMiniApp.exe` ตัวใหม่ทับตัวเดิม

## ฐานข้อมูล

ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม เมื่อเปิดโปรแกรมครั้งแรก ระบบจะสร้างไฟล์ `%LocalAppData%\RentFlowMiniApp\rentflow.db` และสร้างตารางให้เอง

> ห้ามวางไฟล์ฐานข้อมูลในโฟลเดอร์ซิงก์คลาวด์หรือโฟลเดอร์แชร์ระหว่างใช้งาน ไฟล์ฐานข้อมูลและไฟล์สำรองไม่ได้เข้ารหัส และมีชื่อกับเบอร์ผู้เช่าและข้อมูลบัญชีธนาคาร

## การสำรองและกู้คืนข้อมูล

ไฟล์สำรองอยู่ที่ `%LocalAppData%\RentFlowMiniApp\Backups` จัดการได้ที่แท็บ **ตั้งค่าพื้นฐาน** กล่อง **สำรองและกู้คืนข้อมูล**

- **สำรองอัตโนมัติ:** เมื่อเปิดโปรแกรมครั้งแรกของวัน ระบบสร้างไฟล์ `rentflow-ปีเดือนวัน-เวลา.db` และเก็บ 30 ชุดล่าสุด ถ้าสำรองไม่สำเร็จจะแจ้งเตือน แต่ยังใช้งานต่อได้
- **สำรองเอง:** กดปุ่ม **สำรองตอนนี้** เช่น หลังออกบิลหรือรับชำระเสร็จ เพราะข้อมูลที่บันทึกระหว่างวันจะอยู่ในชุดสำรองอัตโนมัติของวันถัดไป
- **คัดลอกออกนอกเครื่อง:** ระบบยังไม่คัดลอกให้อัตโนมัติ ไฟล์สำรองจึงอยู่ในดิสก์เดียวกับข้อมูลจริง ถ้าดิสก์เสียจะหายทั้งหมด กดปุ่ม **เปิดโฟลเดอร์ไฟล์สำรอง** แล้วคัดลอกไฟล์ล่าสุดไปเก็บในแฟลชไดรฟ์เป็นครั้งคราว

วิธีกู้คืน:

1. กดปุ่ม **กู้คืนจากไฟล์สำรอง** แล้วเลือกไฟล์ ชื่อไฟล์บอกวันที่และเวลาที่สำรอง
2. ระบบตรวจว่าไฟล์ไม่เสียหาย มีตารางครบ และไม่ได้มาจากโปรแกรมรุ่นใหม่กว่า ถ้าไม่ผ่านจะแจ้งเตือนโดยไม่แตะข้อมูลปัจจุบัน
3. ยืนยันการกู้คืน ข้อมูลที่บันทึกหลังจากวันที่ของไฟล์สำรองจะหายไป
4. ระบบเก็บข้อมูลปัจจุบันไว้เป็น `rentflow-before-restore-ปีเดือนวัน-เวลา.db` ก่อน แล้วกู้คืนและเปิดโปรแกรมใหม่ ถ้าเลือกไฟล์ผิด ให้กู้คืนจากไฟล์ `before-restore` นี้

ไฟล์ที่ขึ้นต้นด้วย `rentflow-before-update-` และ `rentflow-before-restore-` ไม่ถูกลบอัตโนมัติ

## วิธีเปิดใช้งานโปรแกรม

เปิด PowerShell ที่ Root ของ Repository แล้วรันคำสั่ง:

```powershell
dotnet run --project .\RentFlowMini\RentFlowApp\RentFlowApp.csproj
```

หากไฟล์ `.csproj` อยู่ในตำแหน่งอื่น ให้ปรับเส้นทางให้ตรงกับโครงสร้างโปรเจกต์จริง

## การสร้างไฟล์สำหรับแจกจ่าย

สร้างไฟล์ `.exe` ไฟล์เดียวที่รวม .NET runtime ไว้แล้ว (self-contained) โดยเปิด PowerShell ที่ Root ของ Repository แล้วรัน:

```powershell
dotnet test
dotnet publish .\RentFlowMini\RentFlowApp\RentFlowApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

- ได้ไฟล์ `publish\RentFlowMiniApp.exe` ขนาดประมาณ 120 MB ส่งให้ผู้ใช้ไฟล์นี้ไฟล์เดียว ส่วน `RentFlowMiniApp.pdb` ไม่ต้องส่ง
- `IncludeNativeLibrariesForSelfExtract` รวมไลบรารีของ SQLite ไว้ในไฟล์เดียวกัน ถ้าไม่ใส่ โปรแกรมจะเปิดฐานข้อมูลไม่ได้เมื่อย้ายไปเครื่องอื่น
- โฟลเดอร์ `publish` ไม่ถูกเก็บใน Git
- ก่อนส่งให้ผู้ใช้ ควรลองเปิดไฟล์บนเครื่องที่ไม่มี .NET และลองพิมพ์ใบแจ้งหนี้ 1 ใบ เพราะเทสต์อัตโนมัติยังไม่ได้ลองกับเครื่องพิมพ์จริง
- ห้ามลองเปิดไฟล์ที่ publish บนเครื่องที่มีข้อมูลจริง ถ้าไม่ได้ตั้งใจใช้ข้อมูลนั้น เพราะโปรแกรมทุกรุ่นใช้ฐานข้อมูลเดียวกันที่ `%LocalAppData%\RentFlowMiniApp`
