เอกสารนี้บันทึกงานที่ยังต้องออกแบบและ Implement เพื่อให้ห้องเปลี่ยนจาก `ไม่ว่าง` กลับเป็น `ว่าง` เมื่อผู้เช่าย้ายออก

## สถานะปัจจุบัน

- สถานะห้องคำนวณจากการมี `Tenant.RoomId` ผูกกับห้อง
- มีความสามารถเพิ่มผู้เช่าและผูกผู้เช่ากับห้อง
- ยังไม่มีความสามารถย้ายออก ยกเลิกการผูกห้อง หรือเปลี่ยนสถานะผู้เช่า
- หากไม่เอา `Tenant.RoomId` ออกจากข้อมูล ห้องจะยังแสดงเป็น `ไม่ว่าง`
- มี checkbox ยกเว้น Cable TV ระดับห้อง แต่ยังไม่มีหน้าตั้งราคากลาง Cable TV
- Billing ปัจจุบันยังไม่คำนวณและบันทึกยอด Cable TV จริง

## สิ่งที่ต้องตัดสินใจก่อน Implement

1. เมื่อผู้เช่าย้ายออก ต้องเก็บประวัติผู้เช่าไว้หรือไม่
2. การย้ายออกต้องระบุวันที่ย้ายออกหรือไม่
3. ผู้เช่าหนึ่งรายสามารถมีประวัติหลายห้องได้หรือไม่
4. ต้องมีเหตุผลการย้ายออกหรือหมายเหตุเพิ่มเติมหรือไม่
5. ผู้ใช้งานจะสั่งย้ายออกจากแท็บผู้เช่า หรือจากตารางห้องพัก
6. บิลเก่าของผู้เช่าต้องยังเชื่อมโยงกับข้อมูลเดิมได้หรือไม่

## แนวทางที่เสนอ

ไม่ควรลบข้อมูล `Tenant` เมื่อผู้เช่าย้ายออก เพราะอาจทำให้ประวัติและความสัมพันธ์กับบิลเดิมหายไป

แนวทางที่ควรพิจารณา:

```text
TenantOccupancyHistory
├── TenantId
├── RoomId
├── MoveInDate
└── MoveOutDate (nullable)
```

ห้องจะมีสถานะดังนี้:

- `ไม่ว่าง` เมื่อมีรายการ occupancy ที่ยังไม่มี `MoveOutDate`
- `ว่าง` เมื่อไม่มีรายการ occupancy ที่ยังใช้งานอยู่
- ชื่อผู้เช่าปัจจุบันมาจากรายการ occupancy ที่ยังใช้งานอยู่

## TODO: การแก้ไขการคิดค่า Cable TV

### ข้อกำหนดที่ควรรักษาไว้

- ราคาค่า Cable TV เป็นราคากลางเดียวกันทุกห้อง
- ราคากลางไม่ควรเก็บซ้ำใน `Room`
- ห้องที่เลือกยกเว้น Cable TV ต้องถูกคิดเป็น `0` เฉพาะค่า Cable TV
- การยกเว้น Cable TV ต้องไม่ทำให้ค่าเช่าห้องเป็น `0`
- บิลที่สร้างแล้วต้องเก็บยอด Cable TV ที่คิดจริงไว้เป็น snapshot
- การเปลี่ยนราคากลางมีผลกับบิลรอบใหม่ ไม่เปลี่ยนบิลเก่า

### ความสามารถที่ต้องเพิ่ม

1. หน้าตั้งค่า “ราคากลาง Cable TV”
   - แสดงราคาปัจจุบัน
   - แก้ไขราคาได้
   - ปฏิเสธราคาติดลบ
   - รองรับราคา `0` หาก business rule อนุญาต
2. การตั้งค่ายกเว้นรายห้อง
   - ใช้ checkbox ในหน้าจัดการห้องที่มีอยู่แล้ว
   - แสดงสถานะในรายการห้อง
3. การคำนวณตอนสร้างบิล

   ```text
   โหลด Room
       ↓
   โหลดราคากลาง Cable TV
       ↓
   ถ้ายกเว้น → Cable TV = 0
   ถ้าไม่ยกเว้น → Cable TV = ราคากลาง
       ↓
   บันทึกยอด Cable TV ลง Bill
   ```

4. แสดง `ค่า Cable TV` ในผลสรุปบิลและรวมในยอดรวม

### สิ่งที่ต้องตัดสินใจก่อน Implement

- ราคากลางจะเก็บใน `BillingSettings` หรือแหล่งข้อมูลใด
- ผู้ใช้จะแก้ราคากลางจากแท็บ Billing หรือเมนูตั้งค่าแยก
- ห้องว่างยังต้องคิด Cable TV หรือไม่
- การคิด Cable TV อิงจากห้องหรือผู้เช่าในกรณีมีการย้ายเข้า/ย้ายออกกลางรอบบิล
- ต้องรองรับประวัติการเปลี่ยนราคากลางหรือไม่
- เมื่อไม่พบราคากลาง ระบบต้องหยุดสร้างบิลหรือใช้ค่าเริ่มต้นใด

## งานที่คาดว่าจะต้องทำ

### Domain และ Application

- กำหนด model สำหรับประวัติการเข้าพัก หรือเพิ่มสถานะผู้เช่าตาม business rule ที่ยืนยันแล้ว
- เพิ่ม service สำหรับย้ายออก
- ป้องกันการย้ายออกซ้ำ
- ป้องกันการผูกผู้เช่าซ้ำในห้องเดียวกัน
- อนุญาตให้ห้องที่ว่างแล้วรับผู้เช่ารายใหม่ได้

### Persistence

- ออกแบบ schema และ migration สำหรับสถานะหรือประวัติการเข้าพัก
- ปรับ repository ให้ค้นหาผู้เช่าปัจจุบันของห้องได้
- เพิ่ม integration tests สำหรับการย้ายเข้าและย้ายออก

### UI

- เพิ่มปุ่มหรือคำสั่ง “แจ้งย้ายออก” ในจุดที่ยืนยันแล้ว
- แสดงวันที่ย้ายออกและประวัติเมื่อจำเป็น
- หลังย้ายออกต้อง refresh ตารางห้องให้แสดง `ว่าง` และผู้เช่าเป็น `-`
- ต้องแสดงข้อความยืนยันก่อนดำเนินการ หากการย้ายออกมีผลกับข้อมูลประวัติ
- เพิ่มจุดแก้ไขราคากลาง Cable TV ตามตำแหน่ง UI ที่ยืนยันแล้ว
- แสดงค่า Cable TV ในหน้าสร้างบิลและผลสรุปบิล
