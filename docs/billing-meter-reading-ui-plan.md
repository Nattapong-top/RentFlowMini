# แผนการพัฒนา UI และ Workflow: การบันทึกมิเตอร์น้ำ-ไฟประจำเดือน (Meter Reading UI Plan)

เอกสารนี้กำหนดรายละเอียดการออกแบบและขั้นตอนการพัฒนาหน้าจอ **บันทึกมิเตอร์น้ำ-ไฟประจำเดือน (`MeterReadingTabControl`)** ตามความต้องการของป๋า เพื่อให้พนักงานใช้งานได้สะดวกรวดเร็ว ป้องกันการบันทึกซ้ำซ้อน และจัดการแก้ไขข้อมูลได้อย่างแม่นยำ

**สถานะ:** อนุมัติและกำลังดำเนินการ (In Progress)  
**วันที่:** 2026-10-18  
**เอกสารอ้างอิง:** `docs/billing-meter-reading-plan.md`, `RentFlowApp/UI/MeterReadingTabControl.cs`

## 1. หลักการและกฎทางธุรกิจ (Business Rules & UX Workflow)

1. **การเลือก รอบบิล (Billing Period):**
   - ใช้ ComboBox เลือก **เดือน** (มกราคม - ธันวาคม) และ **ปี พ.ศ.** (เช่น 2568, 2569, 2570)
   - ระบบจะแปลงค่าเป็นรูปแบบสากล `YYYY-MM` (เช่น `2026-10`) เพื่อใช้งานร่วมกับ Domain
2. **การกรองห้องใน Dropdown (Room Filtering):**
   - เมื่อเลือก **รอบบิลใดๆ** ตัวเลือกห้องพักใน Dropdown (`_roomComboBox`) จะ **ซ่อนห้องที่ถูกบันทึกมิเตอร์สำหรับรอบบิลนั้นไปแล้ว** ออกโดยอัตโนมัติ 
   - เหลือแสดงเฉพาะห้องที่ยังไม่ได้บันทึก เพื่อให้พนักงานทราบสถานะและจดไล่ไปทีละห้องได้อย่างสะดวก
3. **การแสดงผลตารางประวัติมิเตอร์ (Grid Filtering & Calculated Units):**
   - ตารางประวัติมิเตอร์ (`_meterGrid`) จะกรองแสดงเฉพาะข้อมูลของ **รอบบิลที่กำลังเลือกอยู่**
   - **การแสดงหน่วยที่ใช้ไป (Units Used):** แยกเป็นคอลัมน์ชัดเจน (**น้ำใช้ไป (หน่วย)** และ **ไฟใช้ไป (หน่วย)**) โดยคำนวณแบบ On-the-fly จาก `Current - Previous` สดๆ ทันที **ไม่ต้องบันทึกลงฐานข้อมูล** เพื่อป้องกันข้อมูลขัดแย้งและรองรับการแก้ไขข้อมูลในอนาคตได้อย่างถูกต้อง
4. **การล็อกค่ามิเตอร์ก่อนหน้า (Locked Previous Readings):**
   - ช่องค่ามิเตอร์ก่อนหน้า (`PrevWater` / `PrevElec`) จะถูกกำหนดเป็น **Read-only (ล็อกห้ามแก้ไข)** เสมอ โดยระบบจะดึงค่าปัจจุบันของรอบบิลก่อนหน้ามาเติมให้อัตโนมัติ (หรือเป็น 0 หากเป็นรอบบิลแรกสุด)
5. **การแก้ไขข้อมูล (Double-click to Edit & Upsert):**
   - หากต้องการแก้ไขข้อมูลที่บันทึกไปแล้ว ให้ **ดับเบิ้ลคลิก** ที่แถวข้อมูลในตาราง ระบบจะดึงข้อมูลห้องและรอบบิลนั้นขึ้นมาแสดงบนฟอร์ม
   - ผู้ใช้สามารถแก้ไขค่าปัจจุบัน (Current) แล้วกดปุ่มบันทึก (หรือกด **Enter**) ระบบจะทำ **การอัปเดต (Update/Upsert)** ข้อมูลเดิมทันที

## 2. ขอบเขตการพัฒนา (Scope of Work)

```text
[Meter Reading UI & Workflow Refinement]
├── Task 1: กรองรายชื่อห้องใน ComboBox เฉพาะห้องที่ยังไม่ถูกบันทึกในรอบบิลที่เลือก
```

- [x] ตารางแสดงเฉพาะข้อมูลของรอบบิลที่เลือก พร้อมคอลัมน์คำนวณหน่วยที่ใช้ไป (น้ำ / ไฟ) แยกชัดเจน
- [x] ดับเบิ้ลคลิกตารางเพื่อโหลดข้อมูลมาแก้ไขได้ และอัปเดตข้อมูลเดิมได้สำเร็จ
- [x] รองรับการกด Enter เพื่อบันทึกข้อมูล
- [x] ช่องค่าก่อนหน้าล็อกเป็น Read-only เสมอ
- [x] Test ผ่าน 100% ไม่มี Regression
